# 技能中心 · 右侧栏

基于 `@linxin666/dsh-client-ui-skill-explorer@0.4.18` 的本地修改版，不是重写技能管理器。保留上游 BSD-3-Clause 授权和图标。

## 使用

打开一个会话，展开右侧边栏；在起始工具页选择 **技能中心**。如果右侧已有其他标签，点击标签栏的 **＋** 打开起始工具页，再选择技能中心。

技能中心在原生右侧标签中打开，不再占用会话中间栏。可使用宿主的拉宽、分栏、浮动及全屏功能。原生右侧栏依附会话，未选择会话时不可用。

- 原有浏览、筛选、创建、导入和编辑界面及 Host 接口不变。
- 每个原生右侧标签有独立编辑状态，隐藏侧栏、切换原生右侧标签或会话时保留。技能中心内部的“技能／创建／导入／编辑”切换仍遵循上游行为，可能卸载未提交的表单；**刷新页面、关闭标签或卸载插件也不会保存未提交表单**。
- 页面保活不会自动重新扫描外部修改。若在其他页面或编辑器中改了技能，返回时请点击技能列表的刷新按钮。
- 保留上游的启停语义：provider 技能的开关可能仅影响本面板视图，不代表已从模型上下文移除。
- 修改版不调用上游匿名统计心跳。

## 构建与检查

需要 Node.js，无需安装构建依赖：

```sh
node build.mjs
node check.mjs
```

`vendor/client-0.4.18.js` 是未修改的上游客户端发行文件。`build.mjs` 用 `src/sidebar.js` 替换其中心页注册和启动入口，叠加 `src/sidebar.css`，生成 `lib/client.js`。`lib/index.js` 为未修改的上游 Host 发行文件。替换边界不匹配时构建会失败，不会静默生成错误版本。

检查覆盖清单、JavaScript 语法、原生右侧标签注册、释放及注册失败清理；这不是浏览器视觉测试。

## 安装与恢复

需要 DSH `>=0.2.2-rc.3`。通过 DSH 插件管理器添加本目录作为本地 bundle，不要手改运行中的 profile。

Bundle 将原插件行 `ui-skill-explorer` 标为停用，并注册 `skill-center-right`。上游程序文件及技能数据不删除；两版使用相同数据接口，不应同时启用。

恢复原版：在插件管理器中**移除本修改版 bundle**，然后确认原技能浏览器已启用；若原版此前被手动停用，需要手动重新启用。仅停用修改版插件行，不会移除 bundle 对原版的停用覆盖。安装或移除后按插件管理器提示刷新或重启。

本地版不会自动合并上游更新。没有引入新的 Host 路由、技能写入逻辑或权限放宽。

本 bundle 不复制个人配置到源码。若原版手动设置了 `dshHome`、`agentsHome` 或插件自身的 `customSkillDirs`，安装前需通过 DSH 插件配置编辑器给修改版设置相同值；否则使用上游默认路径。
